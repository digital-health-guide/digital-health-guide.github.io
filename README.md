# digital-health-guide.github.io

This repository only serves the published website at <https://digital-health-guide.github.io/>.

The site's source now lives in the book's monorepo, in [`digital-health-guide.github.io/`](https://github.com/digital-health-guide/digital-health-guide/tree/main/digital-health-guide.github.io). A GitHub Actions workflow there builds the site and publishes it to this repository's `gh-pages` branch. Do not edit this repository by hand; send changes to the [monorepo](https://github.com/digital-health-guide/digital-health-guide).
