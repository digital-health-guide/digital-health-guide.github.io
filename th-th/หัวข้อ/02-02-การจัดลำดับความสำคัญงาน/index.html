หัวข้อ 2.2 — การจัดลำดับความสำคัญของงาน

สรุปในหนึ่งประโยค: การจัดลำดับความสำคัญคือการเรียงลำดับงานที่ผ่านการคัดกรองมาแล้วอย่างจงใจและโปร่งใส โดยสมดุลคุณค่า ความเร่งด่วน ความเสี่ยง และความพยายามกับกำลังที่มีจำกัด เพื่อให้ ณ ทุกขณะองค์กรทำสิ่งที่มีคุณค่าที่สุดเท่าที่ทำได้ และอธิบายได้ว่าทำไม

ทำไมเรื่องนี้จึงสำคัญในด้านสุขภาพและการดูแล#

การจัดลำดับความสำคัญคือจุดที่กลยุทธ์กลายเป็นจริง กลยุทธ์ที่แท้จริงขององค์กรไม่ใช่แผนที่เผยแพร่ แต่คือลำดับที่มันทำสิ่งต่าง ๆ จริง และในด้านสุขภาพและการดูแล ลำดับนั้นมีผลต่อความปลอดภัย ความเท่าเทียม และเงินสาธารณะ ลดความสำคัญของงานด้านการทำงานร่วมกันได้ ระเบียนการดูแลร่วมก็หยุดชะงัก ลดความสำคัญของหนี้ทางเทคนิค ระบบก็ล่มตอนตีสองในวันหยุดธนาคาร ลดความสำคัญของการแก้ไขด้านการเข้าถึง คุณก็กันผู้ที่ต้องการบริการมากที่สุดออกไป

แรงกดดันเป็นโครงสร้าง ความต้องการเกินกำลังเสมอ และความต้องการส่วนใหญ่ชอบธรรม ผู้นำจึงต้องการวิธีที่ทำให้ข้อแลกเปลี่ยนชัดเจนและปกป้องได้ ไม่ใช่กระบวนการที่อีเมลฉบับล่าสุดชนะหรือทุกโครงการเป็น "ลำดับความสำคัญสูงสุด" การจัดลำดับความสำคัญที่โปร่งใสยังเปลี่ยนบรรยากาศทางการเมือง เมื่อผู้มีส่วนได้ส่วนเสียเห็นเกณฑ์และการเรียงลำดับ การต่อรองเปลี่ยนจากการล็อบบี้ไปเป็นบทสนทนาร่วมเรื่องคุณค่าและต้นทุนของความล่าช้า หัวข้อนี้ต่อจากการรับงานเข้า (หัวข้อ 2.0) และการคัดกรอง (หัวข้อ 2.1) โดยสมมติว่าคุณมีแบ็กล็อกที่มองเห็นได้และผ่านการประเมินแล้วให้เรียง และป้อนวงจรการส่งมอบ (หัวข้อ 3.4–8) และการจัดการพอร์ตโฟลิโอ (หัวข้อ 5.3 — การบริหารพอร์ตโฟลิโอโครงการระดับองค์กร (EPPM))

แนวคิดหลัก#

การจัดลำดับความสำคัญ (prioritisation) เรียงลำดับแบ็กล็อกหรือพอร์ตโฟลิโอ แตกต่างจากการคัดกรอง (ซึ่งประเมินและส่งต่อแต่ละรายการแยกกัน) การจัดลำดับความสำคัญเปรียบเทียบรายการ กับกันและกัน เพื่อแย่งกำลังที่มีจำกัด และทำการเปรียบเทียบนั้นใหม่เมื่อความเป็นจริงเปลี่ยน

ต้นทุนของความล่าช้า (Cost of Delay) คือเลนส์เชิงเศรษฐศาสตร์ที่อยู่ใต้วิธีที่ดีที่สุด คือแต่ละสัปดาห์ที่สิ่งนี้ ไม่ถูกทำ มีต้นทุนเท่าใด ในรูปคุณค่า อันตราย หรือเงิน การทำให้ต้นทุนของความล่าช้าชัดเจนเปลี่ยนกรอบการจัดลำดับความสำคัญจาก "อะไรสำคัญที่สุด?" (ทุกอย่าง) เป็น "อะไรแพงที่สุดหากล่าช้า?" (คำถามที่จัดอันดับได้)

กรอบวิธีทั่วไป แต่ละแบบมีความเหมาะสมของตน

  • WSJF (Weighted Shortest Job First) จาก Scaled Agile Framework (SAFe) คือให้คะแนนต้นทุนของความล่าช้า (คุณค่าต่อผู้ใช้/ธุรกิจ + ความสำคัญด้านเวลา + การลดความเสี่ยง/การเปิดโอกาส) แล้วหารด้วยขนาดงาน WSJF สูงสุดทำก่อน โดยธรรมชาติเอื้อต่องานเล็ก คุณค่าสูง และสำคัญด้านเวลา และไม่สนใจต้นทุนจม
  • RICE (Reach × Impact × Confidence ÷ Effort เป็นที่นิยมโดย Intercom) คือคะแนนการจัดการผลิตภัณฑ์ที่ลดความกระตือรือร้นด้วยปัจจัย Confidence
  • MoSCoW (Must / Should / Could / Won't-this-time) จาก DSDM คือการจัดประเภท ยอดเยี่ยมสำหรับกำหนดขอบเขตรุ่นหรือโครงการที่มีวันที่แน่นอน อ่อนกว่าในฐานะการเรียงลำดับแบบละเอียด
  • คุณค่าเทียบความพยายาม (value-versus-effort) (2×2) คือภาพอย่างรวดเร็วสำหรับมองหาชัยชนะง่ายและหลุมเงิน หยาบแต่เร็ว
  • แบบจำลอง Kano จัดประเภทคุณสมบัติเป็นพื้นฐาน (ต้องมี) สมรรถนะ หรือสร้างความประทับใจ มีประโยชน์ในการสมดุลสิ่งที่ต้องมีกับตัวสร้างความแตกต่าง

ไม่มีกรอบใด "ถูกต้อง" แต่ละแบบเข้ารหัสนิยามคุณค่าที่ต่างกัน และการให้คะแนนร่วมกันมักมีค่ากว่าตัวเลข

การดำเนินงานเทียบการเปลี่ยนแปลง (run versus change) คือสมดุลระดับพอร์ตโฟลิโอ งานปฏิบัติการ "รักษาไฟให้ติด" (run) เทียบกับขีดความสามารถใหม่ (change) การจัดลำดับความสำคัญต้องครอบคลุมทั้งสอง มิฉะนั้นงาน run ที่มองไม่เห็น รวมถึง หนี้ทางเทคนิค (technical debt) และ การแก้ไขด้านความปลอดภัย (safety/security) จะแพ้ทุกการแข่งขันกับคุณสมบัติใหม่ที่เปล่งประกายจนกว่าจะล้มเหลวอย่างหายนะ

แบบอิงกำลังเทียบแบบอิงวันที่ (capacity-based versus date-based) การจัดลำดับความสำคัญแบบอิงกำลังเติมปริมาณงานที่ทราบและจำกัด (จังหวะที่ยั่งยืน) แบบอิงวันที่ทำงานย้อนจากกำหนดเวลาที่เลื่อนไม่ได้ (การขึ้นระบบตามกฎระเบียบ) และใช้ MoSCoW ยืดหยุ่นขอบเขต พอร์ตโฟลิโอส่วนใหญ่ต้องการทั้งสองแบบ ใช้กับรายการต่างกัน

แนวปฏิบัติที่ดี#

  1. เลือกกรอบหลักหนึ่งกรอบและใช้อย่างสม่ำเสมอ เลือกวิธีที่เหมาะกับงานของคุณ ได้แก่ WSJF สำหรับพอร์ตโฟลิโอการเปลี่ยนแปลงแบบผสมที่มีความสำคัญด้านเวลาจริง RICE สำหรับแบ็กล็อกคุณสมบัติผลิตภัณฑ์ MoSCoW สำหรับรุ่นที่มีวันที่แน่นอน และใช้อย่างสม่ำเสมอเพื่อให้คะแนนเปรียบเทียบได้ การเปลี่ยนกรอบทีละรายการทำให้แบ็กล็อกเปรียบเทียบไม่ได้และเชื้อเชิญการเล่นระบบ

  2. ทำให้ต้นทุนของความล่าช้าชัดเจน โดยเฉพาะงานด้านความปลอดภัยและกฎหมาย ถามทุกรายการว่า "ความล่าช้าหนึ่งเดือนมีต้นทุนเท่าใด?" สำหรับการแก้ไขด้านความปลอดภัยหรือกำหนดเวลาตามกฎระเบียบ คำตอบมักรุนแรงและไม่เป็นเส้นตรง ซึ่งเป็นเหตุผลที่ต้องให้คะแนน ไม่ใช่สมมติ ต้นทุนของความล่าช้าคือสกุลเงินร่วมที่ให้กำหนดเวลาด้านการปฏิบัติตามกฎระเบียบกับการปรับปรุงประสบการณ์ผู้ใช้ถูกเปรียบเทียบอย่างซื่อตรง

  3. สงวนกำลังที่ชัดเจนสำหรับ run หนี้ทางเทคนิค และความปลอดภัย อย่าปล่อยให้งานรักษาไฟให้ติด หนี้ทางเทคนิค และการแก้ไขด้านความมั่นคงปลอดภัย/ความปลอดภัยแข่งขันทีละคุณสมบัติกับขีดความสามารถใหม่ มันจะแพ้จนกว่าบางสิ่งจะพัง กันกำลังตามสัดส่วนประจำ (กฎทั่วไปคือส่วนที่มีนัยสำคัญและได้รับการปกป้อง) สำหรับงานนี้ และถือเป็นสิ่งที่ต่อรองไม่ได้

  4. จัดลำดับความสำคัญตามผลลัพธ์และคุณค่า ไม่ใช่ตามตำแหน่งของผู้ขอ ให้คะแนนเทียบกับผลลัพธ์และลำดับความสำคัญที่องค์กรประกาศ (เหมาะที่สุดคือ OKR ดูหัวข้อ 10.0) แทนที่จะดูว่าใครขอ เมื่อรายการของผู้มีส่วนได้ส่วนเสียอาวุโสได้คะแนนต่ำ นั่นคือระบบทำงานถูกต้อง กรอบวิธีให้พื้นฐานที่เป็นธรรมและไม่เป็นเรื่องส่วนตัวในการมีบทสนทนานั้น

  5. จับคู่วิธีกับข้อจำกัด: กำลังหรือวันที่ สำหรับกระแสการเปลี่ยนแปลงที่ยั่งยืน เรียงตามคุณค่าและดึงงานเข้าสู่กำลังที่ทราบ สำหรับวันที่เลื่อนไม่ได้ ทำงานย้อนและใช้ MoSCoW ปกป้อง "Must" และยืดหยุ่น "Could" การสับสนสองอย่างนี้ คือพยายามใส่ขอบเขตคงที่ในเวลาคงที่และกำลังคงที่ เป็นเส้นทางคลาสสิกสู่โครงการที่ล้มเหลว

  6. จัดลำดับความสำคัญอย่างโปร่งใสและต่อรองอย่างเปิดเผย เผยแพร่แบ็กล็อกที่จัดอันดับและการให้คะแนนเบื้องหลัง ความโปร่งใสเปลี่ยนการจัดลำดับความสำคัญจากชุดข้อตกลงส่วนตัวให้เป็นการต่อรองร่วมที่ข้อแลกเปลี่ยนมองเห็นได้ การจะเลื่อนรายการของคุณขึ้น บางสิ่งต้องเลื่อนลง และทุกคนเห็นต้นทุน นี่คือการเคลื่อนไหวที่ลดการเมืองได้ทรงพลังที่สุดเพียงหนึ่งเดียวที่ผู้นำด้านการส่งมอบมี

  7. จัดลำดับความสำคัญใหม่ตามจังหวะปกติ และเฉพาะตอนนั้น กำหนดจังหวะ (เช่นการทบทวนพอร์ตโฟลิโอรายเดือนหรือรายไตรมาส บวกการปรับแต่งแบ็กล็อกแบบเบากว่าระหว่างนั้น) ที่ทบทวนลำดับความสำคัญเทียบกับหลักฐานใหม่ ระหว่างการทบทวน ให้ยืนหยัดเพื่อทีมจะได้มีรันเวย์ที่มั่นคง การจัดลำดับความสำคัญใหม่ตลอดเวลาเป็นอันตรายไม่น้อยกว่าการไม่จัดใหม่เลย คือทำลายการไหลและไม่ทำอะไรเสร็จ

  8. ระวังการเล่นระบบและความแม่นยำเท็จ คะแนนสัมพัทธ์ (Fibonacci ขนาดเสื้อยืด) เป็นการประมาณ ไม่ใช่ความจริง WSJF 8.3 ไม่ได้ดีกว่า 7.9 อย่างมีนัยสำคัญ ใช้ตัวเลขเพื่อ แจ้ง การสนทนาที่จัดอันดับ จับตาข้อมูลนำเข้าที่เกินจริง และให้วิจารณญาณของผู้มีประสบการณ์แทนที่คะแนนที่บิดเบี้ยวอย่างเห็นได้ชัด พร้อมบันทึกเหตุผล

คำถามสำหรับหารือกับทีมของคุณ#

  1. คำตอบที่ซื่อตรงของเราต่อ "ความล่าช้าหนึ่งเดือนมีต้นทุนเท่าใดจริง ๆ?" สำหรับงานที่เราเลื่อนเรื่อยมาคืออะไร? ต้นทุนของความล่าช้าคือสกุลเงินร่วมที่ให้กำหนดเวลาด้านการปฏิบัติตามกฎระเบียบกับการปรับปรุงประสบการณ์ผู้ใช้ถูกเปรียบเทียบอย่างซื่อตรง แต่องค์กรส่วนใหญ่ไม่เคยทำให้ชัดเจนจึงเป็นค่าเริ่มต้น "ทุกอย่างสำคัญ" ซึ่งเป็นข้อความที่จัดอันดับไม่ได้ สิ่งนี้สำคัญอย่างยิ่งในด้านสุขภาพและการดูแลเพราะต้นทุนของการเลื่อนงานบางอย่างรุนแรงและไม่เป็นเส้นตรง การแก้ไขด้านความปลอดภัยหรือการพึ่งพาด้านการทำงานร่วมกันที่เลื่อนไปอาจอยู่เฉย ๆ หลายเดือนแล้วล้มเหลวอย่างหายนะ ขณะที่คุณสมบัติอำนวยความสะดวกที่เลื่อนแทบไม่มีต้นทุน ทีมควรถกว่าพวกเขาอธิบายต้นทุนความล่าช้าของรายการที่เป็นที่โต้แย้งสูงสุดได้จริงหรือไม่ และเผชิญกรณีที่น่าอึดอัดซึ่งคำตอบที่ซื่อตรงคือ "น้อยมาก" สำหรับโครงการยอดนิยม และ "อาจเป็นเหตุการณ์ร้ายแรง" สำหรับโครงการที่มองไม่เห็น มุมมองที่เป็นรูปธรรม คือเอาสามรายการที่ติดอยู่กลางแบ็กล็อกตอนนี้และบังคับให้เขียนประโยคต้นทุนความล่าช้าสำหรับแต่ละรายการ ถามว่าหนี้ทางเทคนิคและการแก้ไขด้านความปลอดภัยเคยถูกให้คะแนนด้วยต้นทุนของความล่าช้าหรือไม่ หรือแพ้ทุกการแข่งขันเพราะไม่เคยเข้าร่วม คำตอบที่ดีแยกรายการที่ต้นทุนความล่าช้าเป็นเส้นตรงคร่าว ๆ ออกจากรายการที่พุ่งสูงที่กำหนดเวลาหรือจุดล้มเหลว และใช้รูปร่างนั้นให้เหตุผลลำดับ ฉบับที่ไม่ซื่อตรงซ่อนอยู่หลัง "ทั้งหมดเป็นลำดับความสำคัญ" ซึ่งคือการไม่มีการจัดลำดับความสำคัญที่คำถามนี้ตั้งใจเปิดเผย

  2. เราเต็มใจกันกำลังไว้เท่าใดสำหรับ run หนี้ทางเทคนิค และความปลอดภัย และเราจะปกป้องมันเมื่อข้อเสนอใหม่ที่เปล่งประกายมาถึงหรือไม่? นี่คือข้อแลกเปลี่ยนที่ผิดพลาดอย่างน่าเชื่อถือที่สุด งานรักษาไฟให้ติด หนี้ทางเทคนิค และการแก้ไขด้านความมั่นคงปลอดภัยหรือความปลอดภัยมองไม่เห็นและแพ้ทีละคุณสมบัติให้ขีดความสามารถใหม่จนกว่าบางสิ่งจะพังตอนตีสองในวันหยุดธนาคาร การถกไม่ใช่ว่าจะปกป้องกำลังบางส่วนหรือไม่ เพราะเกือบทุกคนเห็นด้วยในหลักการ แต่คือสัดส่วนเฉพาะ และที่ยากกว่ามากคือผู้นำจะยืนหยัดเส้นนั้นจริงหรือไม่เมื่อโครงการน่าตื่นเต้นของผู้สนับสนุนอาวุโสต้องการบุกกำลังที่กันไว้เป็นครั้งแรก ในด้านสุขภาพและการดูแล เดิมพันรวมถึงความปลอดภัยของผู้ป่วยและความน่าเชื่อถือของระบบที่แพทย์พึ่งพา การถือส่วนที่กันไว้เป็นสิ่งที่ต่อรองไม่ได้จึงเป็นท่าทีด้านความปลอดภัย ไม่ใช่เพียงสุขอนามัยที่ดี มุมมองที่เป็นรูปธรรม คือย้อนดูเหตุการณ์ใหญ่หรือเหตุการณ์เกือบพลาดครั้งล่าสุดและถามว่าสืบไปถึงงาน run หรือหนี้ที่เลื่อนซึ่งไม่เคยชนะการแข่งขันลำดับความสำคัญหรือไม่ ระบุผู้ที่มีอำนาจปฏิเสธการบุกกำลังที่ได้รับการปกป้องและทดสอบว่าเขาจะทำจริงหรือไม่ คำตอบที่เข้มแข็งให้คำมั่นถึงส่วนที่ได้รับการปกป้องเฉพาะเจาะจง และที่สำคัญคืออธิบายธรรมาภิบาลที่รักษาการปกป้องภายใต้แรงกดดัน แทนการเชื่อเจตนาดี ฉบับที่ซื่อตรงยอมรับว่าการกันกำลังเป็นของจริงก็ต่อเมื่อรอดการปะทะกับผู้มีส่วนได้ส่วนเสียที่ทรงอำนาจที่สุดในห้อง

  3. เมื่อรายการของผู้มีส่วนได้ส่วนเสียอาวุโสได้คะแนนต่ำ เรามีความโปร่งใสและความกล้าพอที่จะปล่อยให้การจัดอันดับคงอยู่หรือไม่? การจัดลำดับความสำคัญตามผลลัพธ์แทนตำแหน่งของผู้ขอฟังดูชัดเจน แต่ผล HiPPO คือความเห็นของผู้ที่ได้รับค่าตอบแทนสูงสุดที่เพิกเฉยต่อคะแนนอย่างเงียบ ๆ เป็นความล้มเหลวเริ่มต้นในบริบท NHS และรัฐบาลที่เป็นลำดับชั้น และกัดกร่อนเพราะเงียบนั่นเอง ความตึงเครียดคือรายการอาวุโสที่ได้คะแนนต่ำมักคือระบบทำงานถูกต้อง แต่หากไม่มีการจัดอันดับที่เผยแพร่อย่างโปร่งใสและเหตุผลการให้คะแนน ผู้นำด้านการส่งมอบไม่มีพื้นฐานที่ไม่เป็นส่วนตัวในการมีบทสนทนานั้นและมักจะยอมอ่อนข้อ ทีมควรถกว่าแบ็กล็อกและคะแนนของพวกเขามองเห็นได้จริงโดยองค์กรผู้ขอหรือไม่ เพราะการต่อรองข้อแลกเปลี่ยนอย่างเปิดเผย "เพื่อเลื่อนรายการของคุณขึ้น รายการที่คะแนนสูงกว่ารายการไหนจะเลื่อนลง และคุณสบายใจกับต้นทุนของความล่าช้านั้นหรือไม่?" เป็นการเคลื่อนไหวที่ลดการเมืองได้ทรงพลังที่สุดเพียงหนึ่งเดียว และใช้ได้เฉพาะที่แจ้ง มุมมองที่เป็นรูปธรรม คือนึกถึงครั้งล่าสุดที่คำขอของผู้อาวุโสแซงคิวและถามว่าจะเกิดอะไรขึ้นหากการจัดอันดับเป็นสาธารณะ พิจารณาเก็บเหตุผลการให้คะแนนเป็นบันทึกธรรมาภิบาลที่คุณแสดงต่อคณะกรรมการ ICB หรือผู้ตรวจสอบได้ คำตอบที่ดีจับคู่ความโปร่งใส (เผยแพร่ลำดับและคะแนน) กับบทพูดที่ซ้อมแล้วและไม่เป็นส่วนตัวสำหรับการสนทนาเรื่องการแทนที่ และระบุผู้ที่มีสถานะถือมัน คำตอบที่เลี่ยงถือเรื่องนี้เป็นสมมติฐาน ในความเป็นจริงเกิดขึ้นเกือบทุกสัปดาห์ และแผนต้องรอดพ้นมัน

  4. เราผูกพันกับกรอบการจัดลำดับความสำคัญหนึ่งกรอบจริงหรือไม่ หรือกำลังให้คะแนนแต่ละรายการอย่างเงียบ ๆ ด้วยวิธีใดก็ตามที่ทำให้รายการนั้นดูดี? การเลือกกรอบหลักหนึ่งกรอบและใช้อย่างสม่ำเสมอคือสิ่งที่ทำให้แบ็กล็อกเปรียบเทียบได้ ในทันทีที่ใช้ WSJF กับข้อเสนอหนึ่ง สัญชาตญาณคุณค่าเทียบความพยายามกับอีกข้อเสนอ และ "ผู้อำนวยการต้องการจริง ๆ" กับข้อที่สาม การเรียงลำดับก็หมดความหมายและการเล่นระบบเริ่มคืบคลาน ความตึงเครียดคือไม่มีกรอบเดียวที่เหมาะกับงานทุกชนิด WSJF เหมาะกับพอร์ตโฟลิโอการเปลี่ยนแปลงแบบผสม RICE กับแบ็กล็อกคุณสมบัติผลิตภัณฑ์ MoSCoW กับรุ่นที่มีวันที่แน่นอน การถกอย่างซื่อตรงจึงคือกรอบใดเป็นวิธี หลัก ของคุณ และที่ไหนที่อนุญาตกรอบที่สองได้อย่างชอบธรรมแทนทางหนีที่สะดวก ในด้านสุขภาพและการดูแล สิ่งนี้สำคัญเพราะกำหนดเวลาด้านการปฏิบัติตามกฎระเบียบ คุณสมบัติที่แพทย์ขอ และการอัปเกรดฐานข้อมูลต้องถูกชั่งบนสเกลเดียวกัน และมีเพียงวิธีที่สม่ำเสมอเท่านั้นที่ให้รายการตามกฎหมายและรายการอำนวยความสะดวกถูกจัดอันดับเทียบกันโดยไม่ต้องอ้อนวอนพิเศษ มุมมองที่เป็นรูปธรรม คือตรวจสอบการตัดสินจัดลำดับความสำคัญสิบสองครั้งล่าสุดและดูว่าใช้วิธีเดียวกันจริงหรือวิธีเปลี่ยนเพื่อให้เหตุผลกับคำตอบที่กำหนดไว้ล่วงหน้า ระวัง "การแสดงกรอบวิธี" ที่การให้คะแนนอันซับซ้อนสร้างตัวเลขที่ไม่มีใครลงมือทำตาม คำตอบที่ดีระบุกรอบหลัก อธิบายกรณีแคบที่มีหลักการซึ่งใช้อีกกรอบ และถือคะแนนเป็นข้อมูลแจ้งการสนทนาที่จัดอันดับ ไม่ใช่ความจริง คำตอบที่อ่อนปล่อยให้ผู้ขอทุกคนนำคณิตศาสตร์ของตนเองมา ซึ่งแยกไม่ออกจากการไม่มีวิธีเลย

  5. เราซื่อตรงเรื่องงานใดผูกกับกำลังและงานใดผูกกับวันที่หรือไม่ หรือพยายามตรึงขอบเขต วันที่ และกำลังพร้อมกัน? การจัดลำดับความสำคัญต้องจับคู่กับข้อจำกัด กระแสการเปลี่ยนแปลงที่ยั่งยืนเรียงตามคุณค่าและดึงเข้าสู่กำลังที่ทราบ ขณะที่การขึ้นระบบตามกฎระเบียบที่เลื่อนไม่ได้ทำงานย้อนจากวันที่ โดย MoSCoW ปกป้อง "Must" และยืดหยุ่น "Could" เส้นทางคลาสสิกสู่โครงการล้มเหลวคือสับสนสองอย่างนี้ ตรึงขอบเขต วันที่ และกำลังพร้อมกัน และเย้ายวนเป็นพิเศษในด้านสุขภาพและการดูแล ที่กำหนดเวลาตามกฎหมายรู้สึกต่อรองไม่ได้และผู้มีส่วนได้ส่วนเสียสมมติว่าขอบเขตเต็มรูปแบบต่อรองไม่ได้เท่ากัน ทีมควรถกทีละรายการว่างานสำคัญแต่ละชิ้นผูกกับกำลังหรือวันที่จริง เพราะการถือโครงการที่ขับเคลื่อนด้วยวันที่เหมือนมีเวลายืดหยุ่น หรือกระแสธุรกิจปกติเหมือนมีกำหนดเวลาแข็ง จัดลำดับความสำคัญผิดทุกอย่างปลายน้ำ มุมมองที่เป็นรูปธรรม คือเอาการขึ้นระบบที่เลื่อนไม่ได้และถามว่าข้อกำหนดใดเป็น "Must" จริงสำหรับขั้นต่ำตามกฎหมายเทียบกับ "Should" หรือ "Could" ที่ถูกลักลอบเข้ามาในชุดบังคับ มองหาโครงการที่ทั้งสามข้อจำกัดถูกตรึงอย่างเงียบ ๆ และระบุว่าอะไรจะยอมเมื่อความเป็นจริงกดดัน คำตอบที่ดีจัดประเภทงานตามข้อจำกัดที่ผูกมัดและใช้วิธีที่ตรงกันอย่างจงใจ รักษากระแสแบบอิงกำลังและการส่งมอบแบบอิงวันที่เป็นวินัยแยกกัน คำตอบที่ไม่สมจริงสัญญาขอบเขตเต็ม ตามวันที่แน่นอน ภายในกำลังคงที่ และหวัง

  6. จังหวะการจัดลำดับความสำคัญใหม่ของเราคืออะไร และเรามีวินัยที่จะรักษาลำดับให้นิ่งระหว่างการทบทวนหรือไม่? ลำดับความสำคัญต้องถูกทบทวนเทียบกับหลักฐานใหม่ แต่ตามจังหวะ คือการทบทวนพอร์ตโฟลิโอรายเดือนหรือรายไตรมาสพร้อมการปรับแต่งที่เบากว่าระหว่างนั้น เพราะการจัดลำดับความสำคัญใหม่ตลอดเวลาเป็นอันตรายไม่น้อยกว่าการไม่จัดใหม่เลย คือทำลายการไหลและไม่ทำอะไรเสร็จ ความตึงเครียดเป็นจริง ความเป็นจริงเปลี่ยนจริง สัญญาณความปลอดภัยใหม่หรือการเปลี่ยนเงินทุนอาจสมควรจัดเรียงใหม่ แต่ทุกการสับเปลี่ยนระหว่างทางทำให้ทีมสูญเสียรันเวย์และทิ้งงานที่สร้างไม่เสร็จครึ่งทางไว้ ในด้านสุขภาพและการดูแล ที่ทีมส่งมอบมักถูกยืดและการพึ่งพาข้ามหลายองค์กร ความปั่นป่วนมีราคาแพงและบั่นทอนขวัญกำลังใจ รันเวย์ที่มั่นคงระหว่างการทบทวนจึงเป็นเรื่องประสิทธิภาพและการรักษาบุคลากรไม่น้อยกว่าการส่งมอบ มุมมองที่เป็นรูปธรรม คือตรวจว่าในไตรมาสที่แล้วส่วนบนของแบ็กล็อกเปลี่ยนกี่ครั้งนอกการทบทวนตามกำหนด และอะไรถูกส่งมอบเป็นผล ตกลงล่วงหน้าเกณฑ์แคบ คือเหตุฉุกเฉินจริง ไม่ใช่ผู้มีส่วนได้ส่วนเสียเสียงดัง ที่ให้เหตุผลทำลายจังหวะ คำตอบที่ดีกำหนดจังหวะที่ชัดเจน ปกป้องรันเวย์ระหว่างการทบทวน และชี้ไปที่งานที่เสร็จจริงเพราะลำดับคงอยู่ได้ คำตอบที่ล้มเหลวจัดลำดับความสำคัญใหม่ทุกครั้งที่อีเมลล่าสุดมาถึง สับสนการเคลื่อนไหวกับการตอบสนองขณะที่ไม่มีอะไรข้ามเส้นชัย

ในทางปฏิบัติ: ตัวอย่างด้านสุขภาพและการดูแล#

ทีมพอร์ตโฟลิโอดิจิทัลของ ICB เผชิญข้อเสนอที่แข่งกันสิบสองข้อและกำลังสำหรับราวห้าข้อ ในอดีตการเรียงลำดับตามความอาวุโสขององค์กร และหนี้ทางเทคนิคไม่เคยปรากฏเลย พวกเขานำ WSJF มาใช้กับงานการเปลี่ยนแปลงและกันกำลังส่วนคงที่ไว้สำหรับ run หนี้ทางเทคนิค และความปลอดภัย

ข้อเสนอแต่ละข้อถูกให้คะแนนร่วมกัน คือคุณค่าทางธุรกิจ ความสำคัญด้านเวลา การลดความเสี่ยง/การเปิดโอกาส และขนาดงาน ในการประชุมเดียวที่มีเสียงจากการส่งมอบ คลินิก และการเงิน กำหนดเวลาการส่งข้อมูลตามกฎหมายได้คะแนนสูงมากด้านความสำคัญด้านเวลา และเพราะขนาดไม่ใหญ่ จึงขึ้นอันดับต้นตาม WSJF แพลตฟอร์มการวิเคราะห์ขนาดใหญ่ที่เป็นที่นิยมได้คะแนนดีด้านคุณค่าแต่ขนาดดันมันลงในลำดับ ผลที่คงคิดไม่ถึงภายใต้การจัดอันดับตามความอาวุโส และกรอบวิธีทำให้ปกป้องได้ การอัปเกรดฐานข้อมูลที่เลื่อนมานานซึ่งเดิมมองไม่เห็นได้รับเงินจากส่วน run ที่กันไว้ก่อนที่มันจะล้มเหลว

ที่สำคัญ แบ็กล็อกที่จัดอันดับและคะแนนถูกแบ่งปันกับองค์กรผู้ขอทั้งหมด เมื่อ trust หนึ่งผลักดันให้ข้อเสนอของตนแซงคิว บทสนทนาไม่ใช่ "คุณรู้จักใคร?" แต่เป็น "รายการที่คะแนนสูงกว่ารายการไหนควรเลื่อนลง และคุณสบายใจกับต้นทุนของความล่าช้านั้นหรือไม่?" การต่อรองเกิดขึ้นอย่างเปิดเผย และ ICB แสดงต่อคณะกรรมการได้ว่าลำดับสะท้อนคุณค่าและต้นทุนของความล่าช้า ไม่ใช่การเมือง

มุมมองตามภาคส่วน#

สตาร์ทอัป#

สตาร์ทอัปด้านสุขภาพดิจิทัลที่ถูกจำกัดด้วยเงินทุนจัดลำดับความสำคัญเทียบกับระยะเวลาเงินทุนเป็นอันดับแรก วิธีเรียงลำดับของมันจึงควรเบาและนำด้วยคุณค่า 2×2 คุณค่าเทียบความพยายามหรือคะแนน RICE แบบง่ายมักเพียงพอ และกลไก WSJF ที่ซับซ้อนเกินจำเป็นสำหรับแบ็กล็อกสามสิบรายการ ต้นทุนของความล่าช้าที่โดดเด่นเป็นเรื่องความอยู่รอด การพลาดหลักฐานที่การประเมินของ NICE หรือลูกค้าหลักต้องการอาจยุติบริษัท ซึ่งจัดอันดับเหนือคุณสมบัติที่มีก็ดีอย่างชัดเจน วินัยที่ยากที่สุดคือการสงวนกำลังใด ๆ สำหรับหนี้ทางเทคนิคและการแก้ไขด้านความปลอดภัยเมื่อทุกสัปดาห์เรียกร้องคุณสมบัติสร้างรายได้ถัดไป แต่การข้ามมันทั้งหมดคือสิ่งที่ทำให้ผลิตภัณฑ์อ่อนวัยติดขัดพอดีตอนขยายขนาด การจัดลำดับความสำคัญใหม่เกิดบ่อยและนำโดยผู้ก่อตั้ง ความเสี่ยงคือความปั่นป่วน ยาแก้คือรักษาลำดับที่มั่นคงอย่างน้อยหนึ่งสปรินต์สั้น ๆ เพื่อให้บางสิ่งถูกส่งมอบจริง

ธุรกิจขนาดเล็ก#

ผู้ให้บริการขนาดเล็กที่ก่อตั้งแล้ว เช่น คลินิก GP ร้านขายยาในชุมชน สถานดูแลผู้สูงอายุ หรือคลินิกแห่งเดียว จัดลำดับความสำคัญโดยแทบไม่มีส่วนเกิน คนไม่กี่คนเดียวกันดำเนินบริการและงานเปลี่ยนแปลงใด ๆ การเรียงลำดับจึงต้องเรียบง่ายอย่างโหดเหี้ยม และ 2×2 คุณค่าเทียบความพยายามที่ใครในทีมก็อ่านได้มีค่ากว่าแบบจำลองการให้คะแนนที่ไม่มีใครมีเวลาดูแล ต้นทุนของความล่าช้าที่โดดเด่นมักเกี่ยวกับกฎหมายหรือความปลอดภัย เช่น กำหนดเวลาของ data-security toolkit การแก้ไขความปลอดภัยทางคลินิก การอัปเกรดระบบตามที่ผู้จัดหาระดับชาติกำหนด และสิ่งเหล่านี้ต้องอยู่บนสุดเพราะผู้ให้บริการขนาดเล็กมีหน้าที่เท่ากับ trust ขนาดใหญ่แต่ไม่มีทรัพยากรรองรับความล้มเหลว การปรับปรุงตามดุลยพินิจแข่งกับการดำเนินบริการจริง วินัยที่ซื่อตรงจึงคือปกป้องเวลาส่วนเล็ก ๆ สม่ำเสมอสำหรับงาน run และการแก้ไขที่ต่อรองไม่ได้ แทนที่จะปล่อยให้แพ้ทุกสัปดาห์ต่อความต้องการที่เผชิญผู้ป่วย เมื่อขีดความสามารถด้านไอทีโดยเฉพาะบางหรือไม่มี "วิธีการ" ส่วนมากถูกกำหนดโดยผู้จัดหาและสัญญากรอบ การจัดลำดับความสำคัญจึงมักเป็นเรื่องการเรียงลำดับการเปลี่ยนแปลงที่ผู้จัดหาขับเคลื่อนและสิ่งไม่กี่อย่างที่คลินิกควบคุมได้ และรักษาลำดับให้นิ่งนานพอที่บางสิ่งจะเสร็จระหว่างสัปดาห์ที่ยุ่งหนึ่งกับอีกสัปดาห์หนึ่ง

องค์กรขนาดใหญ่#

NHS trust หรือ ICS ดำเนินพอร์ตโฟลิโอการเปลี่ยนแปลงแบบผสมที่มีความสำคัญด้านเวลาจริงและพันธะ run หนัก ซึ่งเป็นรูปร่างที่ WSJF และส่วนที่กันไว้สำหรับ run/หนี้ทางเทคนิค/ความปลอดภัยถูกออกแบบมา การเมืองคือความท้าทายที่แท้จริง องค์กรผู้สนับสนุนหลายแห่ง แรงกดดัน HiPPO และความคาดหวังเดิมว่าความอาวุโสกำหนดลำดับ ความโปร่งใสของแบ็กล็อกที่จัดอันดับและคะแนนจึงเป็นเครื่องมือหลักในการลดการเมืองขององค์กรขนาดใหญ่ การจัดลำดับความสำคัญที่นี่ครอบคลุมสำนักงานพอร์ตโฟลิโอและต้องประสานกระแสแบบอิงกำลังสำหรับการเปลี่ยนแปลงตามปกติกับโครงการแบบอิงวันที่ที่ทำงานย้อนจากการขึ้นระบบตามกฎระเบียบที่เลื่อนไม่ได้ ยืดหยุ่นขอบเขตผ่าน MoSCoW เพราะ trust ต้องแสดงหลักฐานความคุ้มค่าเงินต่อคณะกรรมการ ICB และผู้ตรวจสอบ เหตุผลการให้คะแนนจึงถูกเก็บเป็นบันทึกธรรมาภิบาล ไม่ทิ้งเมื่อตัดสินใจแล้ว

ภาครัฐ#

ที่ NHS England, DHSC หรือรัฐบาลที่มีอำนาจแยก การจัดลำดับความสำคัญคือการจัดการพอร์ตโฟลิโอในระดับชาติ ทำเป็นทางการผ่าน Management of Portfolios (MoP) และแบบจำลองห้าเคสของ Treasury ที่ต้นทุนของความล่าช้าวัดในสุขภาพประชากร การปฏิบัติตามกฎหมาย และหลายพันล้านปอนด์ พอร์ตโฟลิโอส่วนใหญ่ไม่ใช่ดุลยพินิจ ได้แก่ การส่งข้อมูลตามบังคับ กำหนดเวลาตามกฎหมาย คำมั่นของรัฐมนตรี วิธีการจึงต้องจัดอันดับ วิธีการ และ เมื่อใด ของงานที่ถูกบังคับ มากกว่าว่าจะทำหรือไม่ และโครงการที่มีวันที่เลื่อนไม่ได้ครอบงำ ความอยากเสี่ยงต่ำและการตรวจสอบเป็นปฏิปักษ์ National Audit Office และ Public Accounts Committee จะทดสอบว่าลำดับสะท้อนคุณค่าและต้นทุนของความล่าช้าหรือเพียงความสะดวกทางการเมือง ฐานการจัดลำดับความสำคัญที่ชัดเจนและเผยแพร่จึงเป็นการป้องกันไม่น้อยกว่าเครื่องมือการจัดการ ความเท่าเทียมเป็นมิติตามกฎหมายของคุณค่า แบบจำลองการให้คะแนนของรัฐบาลจึงควรให้น้ำหนักผลกระทบต่อประชากรที่ได้รับบริการน้อยที่สุด ไม่ใช่เฉพาะประโยชน์รวม มิฉะนั้นจะเอื้อต่อผู้ที่ได้รับบริการดีอยู่แล้วอย่างเป็นระบบ

รูปแบบความล้มเหลวที่พบบ่อย#

  • ทุกอย่างเป็นลำดับความสำคัญหนึ่ง ไม่มีการเรียงลำดับจริง เสียงที่ดังที่สุดหรือกำหนดเวลาที่ใกล้ที่สุดกำกับ วิธีแก้: บังคับการจัดอันดับที่เข้มงวด ไม่อนุญาตให้เสมอกันที่ส่วนบน
  • run และหนี้ทางเทคนิคแพ้เสมอ งานปฏิบัติการและการแก้ไขที่มองไม่เห็นถูกปล่อยให้อดอยากจนล้มเหลว วิธีแก้: กำลังที่กันไว้และได้รับการปกป้อง
  • HiPPO เพิกเฉยคะแนน ความเห็นของผู้ที่ได้รับค่าตอบแทนสูงสุดเพิกเฉยต่อคะแนนอย่างเงียบ ๆ ทุกครั้ง วิธีแก้: คะแนนโปร่งใสและการต่อรองข้อแลกเปลี่ยนอย่างเปิดเผย
  • การแสดงกรอบวิธี การให้คะแนนอันซับซ้อนสร้างตัวเลขที่ไม่มีใครลงมือทำ วิธีแก้: ให้คะแนนแจ้งลำดับที่จัดอันดับจริงและลงมือทำตาม
  • ขอบเขตคงที่ + วันที่คงที่ + กำลังคงที่ ตรึงทั้งสามข้อจำกัด รับประกันความล้มเหลว วิธีแก้: ยืดหยุ่นขอบเขตผ่าน MoSCoW หรือกำลัง หรือวันที่
  • ความปั่นป่วน ลำดับความสำคัญเปลี่ยนทุกสัปดาห์ ไม่มีอะไรเสร็จ วิธีแก้: จังหวะการจัดลำดับความสำคัญใหม่ที่กำหนดและรันเวย์ที่มั่นคงระหว่างนั้น

แบบจำลองระดับวุฒิภาวะ#

มิติ เริ่มต้น พัฒนา ทำให้เป็นมาตรฐาน บริหารจัดการ ประสานบูรณาการ
วิธีและฐาน ไม่มีวิธี เรียงตามความอาวุโสหรือกำหนดเวลา ใช้กรอบอย่างไม่สม่ำเสมอหรือเฉพาะบางงาน ใช้กรอบหลักหนึ่งกรอบอย่างสม่ำเสมอ พิจารณาต้นทุนของความล่าช้า กำกับและปรับเทียบข้อมูลนำเข้าการให้คะแนน วัดการตัดสินจัดลำดับความสำคัญเทียบกับผลลัพธ์ที่ประกาศ ปรับกรอบให้เข้ากับผลลัพธ์/OKR ใช้วิธีแบบอิงกำลังและอิงวันที่อย่างจงใจ
สมดุล run/change และหนี้ทางเทคนิค run และหนี้ทางเทคนิคมองไม่เห็น ให้ทุนเฉพาะงานใหม่ รับรู้ run/หนี้บ้างแต่ไม่มีกำลังที่ได้รับการปกป้อง กำลังที่กันไว้สำหรับ run หนี้ทางเทคนิค และความปลอดภัย ติดตามส่วนที่ได้รับการปกป้องเป็นตัวชี้วัด รับรอง run/หนี้และการแก้ไขด้านความปลอดภัยเทียบกับเป้าหมาย จัดการและทบทวนสมดุล run/change อย่างจริงจังเทียบกับคุณค่า
ความโปร่งใสและจังหวะ ลำดับความสำคัญคลุมเครือ เปลี่ยนแบบตอบสนองและตลอดเวลา แบ็กล็อกมองเห็นได้บางส่วน ทบทวนไม่สม่ำเสมอ เผยแพร่แบ็กล็อกที่จัดอันดับ จังหวะการจัดลำดับความสำคัญใหม่ที่แน่นอน ติดตามการยึดตามจังหวะและความปั่นป่วนของการจัดลำดับใหม่ เก็บเหตุผลการให้คะแนนเป็นบันทึกที่กำกับดูแลสำหรับคณะกรรมการและผู้ตรวจสอบ การต่อรองข้อแลกเปลี่ยนอย่างเปิดเผยเป็นบรรทัดฐาน จังหวะมั่นคง ตรวจสอบความสมเหตุสมผลของคะแนนเทียบกับผลลัพธ์

รายการตรวจสอบ#

  • เลือกกรอบการจัดลำดับความสำคัญหลักหนึ่งกรอบและใช้อย่างสม่ำเสมอ
  • ทำให้ต้นทุนของความล่าช้าชัดเจน โดยเฉพาะงานด้านความปลอดภัยและกฎหมาย
  • กันกำลังสำหรับ run หนี้ทางเทคนิค และงานด้านความปลอดภัย/ความมั่นคงปลอดภัย
  • ให้คะแนนรายการเทียบกับผลลัพธ์/OKR ไม่ใช่ความอาวุโสของผู้ขอ
  • ใช้วิธีแบบอิงกำลังและอิงวันที่กับรายการที่ถูกต้อง
  • เผยแพร่แบ็กล็อกที่จัดอันดับและการให้คะแนนต่อผู้มีส่วนได้ส่วนเสีย
  • ต่อรองข้อแลกเปลี่ยนอย่างเปิดเผย เพื่อเลื่อนรายการหนึ่งขึ้น อีกรายการหนึ่งเลื่อนลง
  • จัดลำดับความสำคัญใหม่ตามจังหวะที่กำหนด พร้อมรันเวย์ที่มั่นคงระหว่างนั้น
  • ถือคะแนนเป็นการประมาณ ระวังการเล่นระบบและความแม่นยำเท็จ
  • อธิบายและปกป้องลำดับปัจจุบันต่อคณะกรรมการได้
